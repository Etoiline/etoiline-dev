# Étoiline

Base minimale Vite avec React et TypeScript. La page actuelle sert uniquement à vérifier le démarrage du projet.

## Démarrage

```sh
npm install
npm run dev
```

Ouvrir l'adresse affichée dans le terminal, par défaut http://localhost:5173.

## Commandes

- `npm run dev` : lancer le serveur de développement.
- `npm run build` : vérifier TypeScript et générer le site dans `dist/`.
- `npm run lint` : vérifier le code avec Oxlint.
- `npm run preview` : prévisualiser le site après compilation.

## Structure

- `src/App.tsx` : composant principal.
- `src/main.tsx` : point d'entrée React.
- `src/index.css` : styles de base.
- `index.html` : document HTML.
- `vite.config.ts` : configuration Vite.
- `tsconfig*.json` : configuration TypeScript.
